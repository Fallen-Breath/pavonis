ResourceLimitConfig (资源限制) ​

resource_limit 部分配置带宽、请求频率、并发请求数与请求超时。global 中的配额对所有站点生效，配额组中的配额只对加入该组的站点生效，两者同时约束一个请求。各项限制的工作方式详见资源限制。

所有字段均为可选。配额中除请求超时默认 1h 外，其余限制不配置即不限。

ResourceLimitConfig ​

字段类型默认值说明
globalResourceQuotaConfig请求超时 1h对所有站点生效的配额
groups[]QuotaGroupConfig无配额组列表，站点通过 quota_group 加入其中一个
max_concurrent_429_responsesint64同时发送的 429 拒绝响应数上限。超出后，新拒绝的请求会被直接中止而不返回响应
idle_client_cache_sizeint10240最多保留多少份暂无请求的 per_client 用量。超出后，最久未访问的用量会被清零

ResourceQuotaConfig (配额) ​

字段类型默认值说明
request_timeoutdurationglobal 中为 1h，配额组中不额外限制单个请求的最长处理时间，使用 Go duration 格式，如 30m、2h、90s。配额组中配置时，取它与全局超时中较短的一个
per_clientClientQuotaConfig不限每个客户端各自一份配额的限制
all_clientsClientQuotaConfig不限所有客户端共用一份配额的限制

QuotaGroupConfig (配额组) ​

配额组包含 ResourceQuotaConfig 的全部字段，另有：

字段类型是否必填说明
idstring是组名，供站点的 quota_group 引用

ClientQuotaConfig (限制项) ​

带宽（令牌桶算法） ​

流量按上传与下载合计计算。

字段类型默认值说明
traffic_avg_mibpsfloat不限平均速率（MiB/s），即令牌桶的填充速率
traffic_burst_mibfloat见下文突发容量（MiB），即令牌桶的桶容量
traffic_max_mibpsfloat不限峰值速率上限（MiB/s）

traffic_burst_mib 未设置时取 traffic_avg_mibps 与 0.125 中的较小值，仅在设置了 traffic_avg_mibps 时生效。

请求 ​

字段类型默认值说明
request_per_secondfloat不限每秒最大请求数
request_per_minutefloat不限每分钟最大请求数
request_per_hourfloat不限每小时最大请求数
request_concurrencyint不限同时处理的最大请求数

请求超出其中任意一项即返回 429 Too Many Requests。

配置示例 ​

限制每个客户端的带宽 ​

yaml
resource_limit:
  global:
    per_client:
      traffic_avg_mibps: 10      # 每个客户端平均 10 MiB/s
      traffic_burst_mib: 20      # 每个客户端允许突发最多 20 MiB
      traffic_max_mibps: 30      # 即使有突发，每个客户端峰值也不超过 30 MiB/s

限制服务器总带宽 ​

yaml
resource_limit:
  global:
    per_client:
      traffic_avg_mibps: 10      # 每个客户端平均 10 MiB/s
    all_clients:
      traffic_avg_mibps: 100     # 所有客户端合计平均 100 MiB/s
      traffic_burst_mib: 50

限制请求频率与并发 ​

yaml
resource_limit:
  global:
    per_client:
      request_per_second: 20
      request_per_minute: 500
      request_concurrency: 8

设置请求超时 ​

yaml
resource_limit:
  global:
    request_timeout: 30m    # 超过 30 分钟的请求将被终止

为部分站点单独设置配额 ​

yaml
resource_limit:
  global:
    per_client:
      request_per_second: 20
  groups:
    - id: downloads
      all_clients:
        request_concurrency: 50
        traffic_avg_mibps: 200

sites:
  - host: gh.example.com
    mode: github
    quota_group: downloads
  - host: hf.example.com
    mode: hugging_face
    self_url: https://hf.example.com
    quota_group: downloads
  # 其他 host 不受 downloads 配额组的影响

GitHub 与 Hugging Face 的请求合计最多同时处理 50 个，总带宽不超过 200 MiB/s，同时仍受 global 中每个客户端每秒 20 个请求的限制。
