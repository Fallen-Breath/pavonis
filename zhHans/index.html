主题

Pavonis无垠数据的门户 - 多功能反向代理服务器

支持容器镜像、GitHub 文件、Hugging Face 模型、PyPI 等多种代理模式，内置 IP 池与流量限速

快速上手
功能介绍
配置参考

容器镜像代理

支持代理 Docker Hub、GHCR、NVCR 等任意 OCI 兼容镜像仓库，可配置访问认证与仓库白黑名单。

GitHub 文件加速

代理 GitHub Releases、Raw 文件、Gist 等下载，支持文本内 URL 自动重写与响应体大小限制。

Hugging Face 下载代理

加速 Hugging Face 模型与数据集文件下载，兼容 huggingface-cli 工具，自动重写重定向链接。

PyPI 镜像

代理 PyPI 包索引，重写 HTML 与 JSON 响应中的下载链接，兼容 pip、uv、Poetry。

通用 HTTP 反代

通过路径映射将不同请求路由到不同上游，支持多种重定向处理策略。

IP 池出站

配置 IPv6 子网池作为出站 IP，支持随机选取与按客户端 IP 哈希固定出站地址。
